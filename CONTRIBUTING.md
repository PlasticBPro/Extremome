# Contributing to the Public Overview

This repository is the public reading layer for Extremome. Contributions should improve the accuracy, accessibility, or navigation of the public project description; they should not reproduce the internal research workspace.

## Useful contributions

- Correct a factual error or an unclear description.
- Improve the explanation of a high-level workflow or repository role.
- Fix a broken link, layout problem, or accessibility issue.
- Suggest a public source that helps verify a statement.

## How to propose a change

1. Create a focused branch from the current main branch.
2. Make a small, clearly scoped change.
3. Open a Pull Request explaining what changed, why it helps readers, and how you checked it.
4. Keep the change open for human review before it is merged. Shared changes are reviewed by Bohui (@bibobrain).

Issues are currently disabled on this public repository. Internal project tasks are tracked through Issues in the private collaboration repositories.

## Keep this repository public-safe

Do not add private Issue or Pull Request identifiers, comment excerpts, local filesystem paths, cluster or deployment settings, credentials, restricted metadata, raw data, unpublished candidate-level results, or detailed internal qualification logic.

Human-readable project documentation is written in English. Preserve exact scientific names and source identifiers when changing them would alter their identity.

A documentation change can make the project easier to understand, but it does not validate a scientific result or imply that the research is complete.
