# Extremome

**Public project overview for the Extremome extreme-environment metagenomics project.**

Extremome is building a reproducible path from public extreme-environment sequencing records to comparable metagenomic outputs, downstream functional analysis, and evidence-linked manuscript work.

**Read the overview:** https://plasticbpro.github.io/Extremome/

This repository is a public reading layer, not a mirror of the private research workspaces. It explains the research workflow, the roles of the core repositories, current work themes, and how the team reviews changes.

## Repository contents

- `index.html` — the GitHub Pages website.
- `CONTRIBUTING.md` — how to suggest changes to this public overview.
- `STATUS.md` — dated high-level status snapshot.
- `.github/PULL_REQUEST_TEMPLATE.md` — prompts for a reviewable change.

The four core research repositories and the supporting web repository are private team workspaces. This page describes their responsibilities and first-level folder roles without publishing private task discussions, detailed implementation internals, or unpublished candidate-level results.
