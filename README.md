# Extremome

**Public project overview for the Extremome extreme-environment metagenomics project.**

Extremome is building a shared path from public extreme-environment sequencing records to comparable metagenomic outputs, downstream functional analysis, and eventually paper-facing evidence.

This repository is intentionally a **public reading layer**. It explains the project, repository map, contribution workflow, current workstreams, and scientific boundaries without mirroring private operational infrastructure or unpublished analysis.

## Read the project overview

Open **[the project overview](./index.html)**. When GitHub Pages is enabled for this repository, the same page is served as the project website.

The overview covers the high-level research pipeline, the four core research repositories and the supporting web layer, the main upstream folders, the Issue-to-Pull-Request workflow, the current project status, and the boundary between public project information and private operational detail.

## Current collaboration repositories

The active working repositories are currently team-access repositories:

- `Extremome-upstream-source-literature-baseline` — papers, public records, source context, and Run-level metadata;
- `Extremome-upstream` — shared metagenomic processing pipeline;
- `Extremome-analysis` — downstream analysis and method integration;
- `Extremome-paper` — manuscript, figures, source data, and reproducibility dependencies.

`Extremome-web` is a separate supporting repository for the project result portal and web interface. It is not treated as another scientific stage.

This public repository does not mirror those repositories. It only exposes the project-level information needed to understand how the work is organized.
